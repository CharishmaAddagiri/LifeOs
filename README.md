# LifeOS 🌸✨

### Your Beautiful AI-Powered Life Operating System

LifeOS is a modern full-stack productivity and wellness platform designed to help students and individuals manage daily life efficiently in one beautiful dashboard.

Track your tasks, habits, mood, sleep, water intake, nutrition, fitness, coding progress, goals, and productivity — all in a clean aesthetic interface with an integrated AI assistant.

# ⚙️ How It Works

1. Users create an account or log in
2. Daily activities are stored in SQLite
3. Data is tracked separately by date
4. Analytics & progress are generated dynamically
5. AI assistant retrieves and analyzes user history
